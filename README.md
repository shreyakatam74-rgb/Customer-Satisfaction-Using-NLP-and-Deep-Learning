# Case Study 2: Predicting Customer Satisfaction Using NLP and Deep Learning

## Overview
This repository contains the full pipeline, SQL queries, Python scripts, and data extracts for **Case Study 2: Predicting Customer Satisfaction Using NLP and Deep Learning**.

## Contents
- `raw_sheet.csv` — cleaned dataset extract from the provided Excel workbook.
- `analysis.py` — Python script containing EDA, modeling, and visualization code.
- `sql_queries.sql` — MySQL queries for data extraction and preparation.
- `model.pkl` — serialized trained model (if applicable).
- `images/` — sample output plots for reporting.
- `README.md` — documentation and usage instructions.
- `requirements.txt` — Python dependencies.
- `.gitignore` — git ignore rules.

## How to Run
1. Create a virtual environment and install dependencies:
   ```bash
   python -m venv venv
   source venv/bin/activate   # or venv\Scripts\activate on Windows
   pip install -r requirements.txt
   ```

2. Run the main analysis:
   ```bash
   python analysis.py
   ```

3. Import the CSVs into Power BI and use provided measures/visuals (see README notes inside).

## Deliverables
- Statistical analysis results
- Machine learning models
- Power BI dashboard instructions
